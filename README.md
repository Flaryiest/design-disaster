# design-disaster

## About
Hello! This is a React.js and CSS projects, where I wanted to push myself a bit with CSS.  
Inspired by YC websites I have seen, I wanted a clean but unique design, and with an emphasis on elegance.  
I have not yet decided what I will actually use this design/website for, so it just looks pretty for now :)  

## Running
The code is relatively easy to set up and run, and doesn't have many dependencies  

Simply clone the repository, make sure you have npm installed and:  
    npm install  
    npm run dev  
And you should be good to go!
